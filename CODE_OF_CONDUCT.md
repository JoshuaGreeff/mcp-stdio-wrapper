# Code of Conduct

## Our Standard

This project aims to be straightforward, respectful, and useful to contributors and users.

Examples of good behavior:

- being specific and constructive in technical discussions
- assuming good intent while reviewing ideas and code
- focusing feedback on the work, not the person
- documenting behavior changes clearly

Examples of unacceptable behavior:

- harassment or personal attacks
- hostile or dismissive conduct
- bad-faith issue spam or disruptive behavior
- publishing private security details before responsible disclosure

## Scope

This Code of Conduct applies in project issues, pull requests, discussions, and other project-managed spaces.

## Enforcement

The maintainer may remove, edit, or reject comments, commits, code, issues, and other contributions that do not align with this Code of Conduct.

## Reporting

If you experience or witness unacceptable behavior, contact the maintainer privately through GitHub.
